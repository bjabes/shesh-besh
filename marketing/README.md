# Gammonade — Marketing Pack

Source assets for the App Store listing, TestFlight beta-review reference, and any press / portfolio use.

## Layout

```
marketing/
  icon/
    icon-1024.png              App Store marketing icon — 1024×1024 PNG, no alpha
  screenshots/
    iphone-6.9/                App Store-required size (iPhone 17 Pro Max)
    iphone-6.3/                Reference size (iPhone 17)
```

App preview videos are not yet produced. If added, drop them under `marketing/preview-videos/` keyed by device size.

## App Store icon

`icon/icon-1024.png` is a copy of `SheshBesh/Assets.xcassets/AppIcon.appiconset/AppIcon-1024.png`. App Store Connect rejects icons with an alpha channel; verify before upload:

```sh
sips -g hasAlpha marketing/icon/icon-1024.png   # expect: hasAlpha: no
```

If a future redesign reintroduces alpha, strip it with:

```sh
sips -s format png -s hasAlpha no marketing/icon/icon-1024.png --out marketing/icon/icon-1024.png
```

## Screenshots

Generated by `scripts/capture-marketing-screenshots.sh`, which runs `SheshBeshUITests/PRScreenshotsTests` against the configured simulators and exports the named attachments as PNGs.

```sh
./scripts/capture-marketing-screenshots.sh
```

By default, captures both `iphone-6.9` (iPhone 17 Pro Max — required by App Store) and `iphone-6.3` (iPhone 17 — reference). Override with:

```sh
MARKETING_SCREENSHOT_DEVICES="iphone-6.9:iPhone 17 Pro Max" \
  ./scripts/capture-marketing-screenshots.sh
```

The six scenes are defined in `SheshBeshUITests/PRScreenshotsTests.swift`:

- `board-opening-pre-roll` — fresh match, awaiting opening roll
- `board-opening-rolled-6-1` — dice rolled, possible moves visible
- `board-opening-after-first-turn` — after opener completes their turn
- `rivalries-home` — rivals list (main entry screen)
- `match-end-you-won` — match completion sheet, user victory
- `match-end-rival-won` — match completion sheet, opponent victory

## Regeneration

Anytime the UI changes meaningfully:

1. `./scripts/capture-marketing-screenshots.sh`
2. Eyeball the diffs in `marketing/screenshots/iphone-6.9/`
3. Commit any updates alongside the UI change

Marketing screenshots intentionally live in the repo (not gitignored) so the App Store-ready pack is always reproducible and reviewable.
