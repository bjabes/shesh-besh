# Gammonade — Marketing Pack

Source assets for the App Store listing, TestFlight beta-review reference, and any press / portfolio use.

The contents of `icon/` and `screenshots/` are **generated** by `scripts/build-marketing-pack.sh` and gitignored. Run the script before any App Store Connect upload — there are no checked-in binaries to drift out of date.

## Layout (after running the script)

```
marketing/
  icon/
    icon-1024.png              App Store marketing icon — 1024×1024 PNG, no alpha
  screenshots/
    iphone-6.9/                App Store-required size (iPhone 17 Pro Max class)
    iphone-6.5/                Legacy required size (iPhone 11 Pro Max class)
    iphone-6.3/                Reference size (iPhone 17)
```

App preview videos are not yet produced. If added, drop them under `marketing/preview-videos/` keyed by device size.

## App Store icon

`icon/icon-1024.png` is generated by `scripts/build-marketing-pack.sh` from `SheshBesh/Assets.xcassets/AppIcon.appiconset/AppIcon-1024.png`. The script copies the asset, strips the alpha channel (App Store Connect rejects icons with alpha), and verifies with `sips -g hasAlpha` before exiting.

The asset catalog is the source of truth — to redesign the icon, replace `AppIcon-1024.png` (and the other size variants) inside `Assets.xcassets/AppIcon.appiconset/`, then re-run the script.

## Screenshots

The script runs `SheshBeshUITests/PRScreenshotsTests` against the configured simulators and exports the named attachments as PNGs.

```sh
./scripts/build-marketing-pack.sh
```

Defaults capture three sizes: `iphone-6.9` (iPhone 17 Pro Max — required by App Store), `iphone-6.5` (iPhone 11 Pro Max — required for older device class), and `iphone-6.3` (iPhone 17 — reference). Override with:

```sh
MARKETING_SCREENSHOT_DEVICES="iphone-6.9:iPhone 17 Pro Max" \
  ./scripts/build-marketing-pack.sh
```

The six scenes are defined in `SheshBeshUITests/PRScreenshotsTests.swift`:

- `board-opening-pre-roll` — fresh match, awaiting opening roll
- `board-opening-rolled-6-1` — dice rolled, possible moves visible
- `board-opening-after-first-turn` — after opener completes their turn
- `rivalries-home` — rivals list (main entry screen)
- `match-end-you-won` — match completion sheet, user victory
- `match-end-rival-won` — match completion sheet, opponent victory

## Workflow

Before uploading to App Store Connect:

1. `./scripts/build-marketing-pack.sh`
2. Eyeball the outputs in `marketing/screenshots/iphone-6.9/` and `marketing/icon/`.
3. Upload to App Store Connect.

Outputs are gitignored intentionally: the asset catalog and the test scenes are the source of truth, and the binaries are reproducible from a clean checkout. Don't commit them.
